## 🧩 About

**STALKER 2 Companion** is a curated list of STALKER 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar viewer, marker switcher
- **Quality-of-Life Helpers** — inventory catalog, loadout manager, overlay notes
- **Research Notes** — route layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Marker Switcher — mark points of interest from any checkpoint
- Show Radar — visualize nearby zones and loot markers
- Route Notes — record and review exploration runs
- Playback Speed — adjust study playback for review (0.1x to 5x)

### Wallhack
- Item Catalog — browse gear, artifacts, ammo, and upgrades
- Custom Loadout Notes — organize stash and equipment
- HUD Visibility — improved on-screen clarity

### Aimbot
- Route Mode Notes — segment study on any map layout
- Stance Control Notes — manually switch stance for study
- Movement Buffer Notes — chain complex maneuvers in the editor
